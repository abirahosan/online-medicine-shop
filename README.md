## Tech Stack
- PHP (MVC architecture)
- MySQL (mysqli with prepared statements)
- HTML, CSS, JavaScript
- AJAX/JSON
- XAMPP (local development)

## Setup Instructions
1. Clone the repository
2. Import `config/database.sql` into phpMyAdmin
3. Place project folder in `htdocs/`
4. Run at `http://localhost/online-medicine-shop/`
5. Default admin login:
   - Email: admin@medicine.com
   - Password: admin123

## Database
Shared schema includes: users, categories, medicines, cart, orders, order_items, payments
